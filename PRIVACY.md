# Privacy Policy

Last updated: August 2026

## Overview

KHOA KIM ERP Tools is an internal productivity extension for the KHOA KIM ERP system.

## Information We Collect

The extension stores only the information necessary for its functionality, including:

- User display name
- User-created order tags
- Saved filter profiles
- Extension preferences

The extension does **not** collect:

- Passwords
- Payment information
- Browsing history
- Personal files
- Emails
- Contacts

## How Information Is Used

The stored information is used only to:

- Synchronize order tags
- Synchronize saved filter profiles
- Improve productivity inside the KHOA KIM ERP system

## Data Storage

Cloud synchronization uses the company's Supabase project.

## Data Sharing

We do not sell user data.

We do not share user data with advertisers.

We do not use user data for marketing.
